## หลักคิดของงานนี้ (สั้น ๆ)

**ฝั่งเซลล์ (LIFF) = เครื่องมือหน้างาน** ใช้กลางแดด มือเดียว เน็ตไม่แรง
- ขาวดำคอนทราสต์สูง อ่านกลางแดดได้, ปุ่มสูง 48px, ปุ่มหลักอยู่ล่างจอ (นิ้วโป้งถึง)
- หน้าแรกตอบคำถามเดียว: **"วันนี้ต้องไปตามงานไหน"** — ตัวเลขใหญ่ + แถบ 7 วันข้างหน้า
- ฟอร์มเรียงตามลำดับที่เซลล์ทำจริงหน้างาน: ปักตำแหน่ง → ถ่ายรูป → เบอร์ (ตรวจซ้ำทันที) → รายละเอียด → นัดตามต่อ
- ทุกการบันทึกจบด้วย "การ์ดในกลุ่ม" ที่เห็นก่อนส่ง — ตอบโจทย์ "ให้กลุ่มเห็น activity เหมือนเดิม"

**ฝั่งแอดมิน = ห้องควบคุม** ดูบนคอม ตัดสินใจเรื่องคน
- หน้าแรกตอบ: **"ทีมวิ่งงานเท่าไหร่ ปิดได้เท่าไหร่ ใครต้องช่วย"**
- หน้า "รายงาน" คือหัวใจ — ตารางคะแนนเซลล์ที่มีแถบผลลัพธ์ (จบได้/ติดตาม/จบที่อื่น) ในแต่ละแถว + เจาะรายคน/พื้นที่/สาเหตุ
- ตารางหน้างานคอลัมน์ตรงกับ Excel เดิม → Export ได้หน้าตาเหมือนที่ทีมคุ้น

**สถานะใช้สีตามความหมายเสมอ** และมีไอคอน+ข้อความกำกับ ไม่ใช้สีอย่างเดียว
| สถานะ | สี | เหตุผล |
|---|---|---|
| จบได้ | success เขียว | ผลลัพธ์ดี |
| จบที่อื่น | danger แดง | เสียงาน |
| เลยกำหนดตาม | warning ส้ม | ต้องรีบทำ |
| ต้องตามวันนี้ | ดำทึบ | งานหลักของวัน |
| ตามต่อ (ยังไม่ถึงกำหนด) | เทาเส้นขอบ | ปกติ |
| ยกเลิก | เทาจาง | ไม่นับ |
