# 02 — LIFF (ฝั่งเซลล์) ทุกหน้าจอ

ผู้ใช้: เซลล์ภาคสนาม เปิดจากลิงก์ในประกาศกลุ่ม LINE · LIFF size: **Full** (ฟอร์มยาว + กล้อง)
งานหลัก 3 อย่าง: **รายงานงานใหม่ · อัปเดตงานเดิม · ดูว่าวันนี้ต้องตามอะไร**

## แผนผังหน้าจอ

```
[L0 กำลังเข้าสู่ระบบ]
   ├─ ใหม่ ────────► [L1 ลงทะเบียน] ─► [L2 รออนุมัติ]
   ├─ ปิดบัญชี ─────► [L3 บัญชีถูกปิด]
   └─ active ──────► [L4 งานของฉัน] ──┬─► [L5 รายงานงานใหม่] ─(พบซ้ำ)─► [L6 ชีทงานที่อาจซ้ำ]
                                      │          └─► [L8 ส่งสำเร็จ]
                                      ├─► [L7 รายละเอียดหน้างาน] ─► [L9 อัปเดตงาน] ─► [L8]
                                      └─► [L10 ผลงานของฉัน]
การ์ดในกลุ่ม (Flex) ─ กด "ดูรายละเอียด" ─► [L7] (deep link /sites/:code)
```

Navigation: ไม่มี tab bar ด้านล่าง (มีแค่ 2 ปลายทางหลัก) — หน้า L4 มีปุ่ม "รายงานงานใหม่" ลอยล่างจอ และไอคอน "ผลงานของฉัน" มุมขวาบน

---

## L0 — กำลังเข้าสู่ระบบ
- โลโก้/ชื่อระบบเล็ก ๆ กลางจอ + spinner + "กำลังเข้าสู่ระบบด้วย LINE"
- ถ้าเกิน 8 วินาที: "เชื่อมต่อช้า" + ปุ่ม **ลองอีกครั้ง** (เรียก auth ซ้ำ — ไม่ใช่ `liff.login()`)
- ถ้าเปิดนอกแอป LINE: "กรุณาเปิดลิงก์นี้จากกลุ่ม LINE ของทีม" (ไม่แสดงฟอร์มใด ๆ)

│ พื้นที่ที่ดูแล              │
│ [ อ.เมือง, อ.โนนสูง ▾ ]    │  ← multi-select อำเภอจาก config
│ เบอร์โทรของคุณ             │

- ชื่อเล่นจำเป็น (ใช้แสดงในรายงาน/การ์ด) · พื้นที่เลือกจากรายการ (ให้ข้อมูลรายงานตามพื้นที่สะอาด)

## L2 — รอแอดมินอนุมัติ
- ไอคอนนาฬิกา + "ส่งข้อมูลแล้ว รอแอดมินอนุมัติ" + สรุปข้อมูลที่กรอก + "แอดมินจะได้รับแจ้งทันที"
- ปุ่ม **ตรวจสอบสถานะ** (เรียก auth ใหม่) และ **ปิด**

## L3 — บัญชีถูกปิดใช้งาน
- "บัญชีนี้ถูกปิดใช้งาน ติดต่อแอดมินของทีม" + ปุ่ม **ปิด**

## L4 — งานของฉัน (หน้าแรก) ★
ตอบคำถาม "วันนี้ต้องไปตามงานไหน" เป็นอย่างแรก

```
┌──────────────────────────────┐
│ (avatar) บอม · อ.เมือง   [📊] │  ← 📊 = ผลงานของฉัน
├──────────────────────────────┤
│ วันนี้ต้องตาม                  │
│ 3  งาน                        │  ← display 56px Heavy (จุดเด่นเดียวของแอป)
│ เลยกำหนด 2 งาน · ติดตามอยู่ 14  │  ← ส้ม / เทา
│                              │
│ จ  อ  พ  พฤ ศ  ส  อา           │  ← แถบ 7 วัน
│ 17 18 19 20 21 22 23          │     วันนี้ = ช่องดำ
│ ●3 ●1 ·  ●2 ·  ·  ●1          │     จุด = จำนวนงานนัดตาม แตะเพื่อกรองวันนั้น
├──────────────────────────────┤
│ [ต้องตาม] [เลยกำหนด 2] [ทั้งหมด] │  ← segmented (shadcn Tabs)
│ 🔍 ค้นหาชื่อ เบอร์ รหัสงาน       │
├──────────────────────────────┤
│ #690825-02          ⏰ เลย 2 วัน│ ← การ์ดงาน (เส้นขอบ ไม่ใช้เงา)
│ คุณพี · ช่างกวาง                │
│ ต.หนองตะไก้ อ.สูงเนิน           │
│ ครั้งที่ 4 · ล่าสุด 15 ต.ค.      │
│ [📞 โทร]  [🧭 นำทาง]  [อัปเดต]   │ ← ปุ่มลัด 3 ปุ่มในการ์ด
├──────────────────────────────┤
│ ...                          │
│                              │
│ ┌──────────────────────────┐ │
│ │ ＋ รายงานงานใหม่            │ │ ← ปุ่มดำเต็มความกว้าง ลอยล่างจอ (safe-area)
│ └──────────────────────────┘ │
└──────────────────────────────┘
```
**การ์ดงาน (SiteCard)**
| ส่วน | รายละเอียด |
|---|---|
| บรรทัด 1 | รหัสงาน (Inter 700) ซ้าย · ป้ายสถานะขวา |
| บรรทัด 2 | ชื่อลูกค้า · ช่าง (heading 18px) |
| บรรทัด 3 | ตำบล อำเภอ (small, เทา) |
| บรรทัด 4 | ครั้งที่ติดตาม · วันที่ล่าสุด |
| ปุ่ม | โทร (`tel:`) · นำทาง (Google Maps) · อัปเดต (ไป L9) |
| แตะพื้นที่อื่น | ไป L7 |

**ป้ายสถานะในการ์ด**
| เงื่อนไข | ป้าย |
|---|---|
| ตามต่อ วันนี้ | ดำทึบ "ตามวันนี้" |
| ตามต่อ เลยกำหนด | ส้ม soft "⏰ เลย 2 วัน" |
| ตามต่อ อนาคต | เทาเส้นขอบ "อีก 3 วัน" |
| จบได้ | เขียว soft "✓ จบได้" |
| จบที่อื่น | แดง soft "✕ จบที่อื่น" |

**สถานะพิเศษ:** โหลด = skeleton 3 การ์ด · ว่าง = "ไม่มีงานต้องตามวันนี้" + ปุ่มรายงานงานใหม่ · ออฟไลน์ = แถบเทาบนสุด "ไม่มีอินเทอร์เน็ต — ข้อมูลอาจไม่ล่าสุด"

## L5 — รายงานงานใหม่ ★
หน้าเดียวเลื่อนลง แบ่ง 4 ส่วนตามลำดับที่ทำจริงหน้างาน · ปุ่มส่งติดล่างจอ · บันทึกร่างอัตโนมัติ

│                              │
│ รูปหน้างาน (1–3)              │

│ ชื่อลูกค้า                     │
│ [                       ]     │
│ ชื่อช่าง                       │
│ [ แคน                   ]     │

│ (เทฐาน)(ตั้งเสา)(ขึ้นโครง)(รอมุง)…│ ← chips จาก config เลื่อนแนวนอน

│ │ ส่ง  บันทึกและส่งเข้ากลุ่ม    │ │ ← sticky bottom, disabled จนกรอกช่อง * ครบ
│ └──────────────────────────┘ │
│  ขาด: ตำแหน่ง, รูป              │ ← บอกสิ่งที่ยังขาดเหนือปุ่ม

**ช่องบังคับ:** ตำแหน่ง · รูป ≥1 · เบอร์ (หรือชื่อ อย่างใดอย่างหนึ่ง) · ตามต่อ (ปรับได้จาก config)
**ลำดับกดส่ง:** อัปโหลดรูป (แถบความคืบหน้าทีละรูป) → บันทึก → `sendMessages` → L8
**ตรวจซ้ำ 2 จังหวะ:** (1) ทันทีที่เบอร์ครบ/ได้พิกัด → แถบเตือนใต้ช่อง (2) ตอนกดส่ง ถ้ายังมี → L6

## L8 — ส่งสำเร็จ
- ไอคอนเช็กเขียว + **"ส่งเข้ากลุ่มแล้ว"** + รหัสงาน
- แสดง **ภาพย่อการ์ดที่ขึ้นในกลุ่ม** (ให้เซลล์เห็นว่าคนอื่นเห็นอะไร)
- ถ้าส่งเข้ากลุ่มไม่ได้: ไอคอนส้ม + "บันทึกแล้ว แต่ส่งการ์ดเข้ากลุ่มไม่ได้ เพราะไม่ได้เปิดจากกลุ่ม" + ปุ่ม **คัดลอกข้อความ** (เพื่อวางในกลุ่มเอง)
- ปุ่ม: **กลับไปที่กลุ่ม** (`liff.closeWindow()`, หลัก) · **รายงานงานถัดไป** (รอง)

## L10 — ผลงานของฉัน
- ช่วงเวลา: (สัปดาห์นี้)(เดือนนี้)(ปีนี้)
- 4 ตัวเลข: วิ่งงาน · งานใหม่ · จบได้ · อัตราปิดงาน % (เทียบค่าเฉลี่ยทีม เป็นข้อความ "ทีม 32%")
- แถบผลลัพธ์ 1 แท่ง: จบได้/ตามต่อ/จบที่อื่น
- "ตามตรงเวลา 85%" (follow-up ที่ทำภายในวันนัด)
- ไม่มีอันดับเทียบรายคน (ป้องกันแรงกดดันในทีม — ให้แอดมินดูแทน)
