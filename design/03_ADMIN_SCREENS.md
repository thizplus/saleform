# 03 — Admin (ฝั่งแอดมิน) ทุกหน้า

ผู้ใช้: น้าอร / หัวหน้าเซลล์ (viewer หรือ admin) · desktop เป็นหลัก ใช้ได้บน tablet/มือถือ
คำถามที่ระบบต้องตอบ: **ทีมวิ่งงานเท่าไหร่ · ปิดได้เท่าไหร่ · ใครต้องช่วย · งานไหนหลุด**

## A2 — รายงานประสิทธิภาพ ★ (หัวใจของ requirement)
แท็บ: **ทีม · รายบุคคล · พื้นที่ · สาเหตุจบที่อื่น**  ·  ตัวกรอง: ช่วงเวลา (global) · มุมมอง (วัน/เดือน/ปี) · เซลล์ · อำเภอ

**แท็บ ทีม — ตารางคะแนนเซลล์ (Scoreboard)**
| คอลัมน์ | ความหมาย |
|---|---|
| เซลล์ | avatar + ชื่อเล่น + พื้นที่ |
| วิ่งงาน | จำนวนครั้งที่รายงาน (ใหม่+ติดตาม) |
| งานใหม่ | หน้างานใหม่ที่เปิด |
| ติดตาม | ครั้งที่ follow-up |
| ผลลัพธ์ | **แถบ stacked** จบได้/ตามต่อ/จบที่อื่น + ตัวเลขกำกับ (hover = tooltip) |
| ปิดได้ % | จบได้ ÷ (จบได้+จบที่อื่น) |
| ตามตรงเวลา % | follow-up ภายในวันนัด |
| เลยกำหนด | จำนวนงานที่เลยวันนัด (ส้ม) |
| เฉลี่ยวันปิดงาน | วันจากเปิดงานถึงจบได้ |
- เรียงได้ทุกคอลัมน์ · แถวล่างสุด = รวมทีม · ปุ่ม "ดูเป็นกราฟ" สลับเป็น bar chart แนวนอน
- ด้านบนตาราง: กราฟแนวโน้ม 1 กราฟ เลือก metric ได้ (วิ่งงาน / จบได้ / ปิดได้%)

**แท็บ พื้นที่**
- ตาราง อำเภอ × (วิ่งงาน, ใหม่, จบได้, จบที่อื่น, ติดตาม, ปิดได้%) ขยายลงเป็นตำบลได้
- แผนที่หน้างาน (pin สีตามสถานะ) ด้านขวา — คลิก pin เปิด A5

**แท็บ สาเหตุจบที่อื่น**
- bar แนวนอน เรียงมาก→น้อย (สาเหตุ) + bar คู่แข่ง (จบที่ร้านไหน)
- กรองตามเซลล์/พื้นที่ได้ · คลิกแท่ง → รายการหน้างานที่จบด้วยสาเหตุนั้น

## A4 — หน้างาน (รายการ)
- **Data table** (shadcn + TanStack Table) คอลัมน์ตามชีท Excel เดิม:
  `NO. · วันที่ · ชื่อลูกค้า · เบอร์ · ช่าง · ลูกค้าเก่า/ใหม่ · ตำบล · อำเภอ · ผู้ตัดสินใจ · สถานะ · ตามล่าสุด · ตามครั้งถัดไป · ครั้ง · เซลล์`
- แถบตัวกรองบรรทัดเดียว: ค้นหา · สถานะ (multi) · เซลล์ · อำเภอ · ช่วงวันที่ · "เลยกำหนดเท่านั้น"
- เลือกคอลัมน์ที่แสดงได้ (column visibility) · แบ่งหน้า 50 แถว · คลิกแถว → A5
- ปุ่มขวาบน: **Export Excel** (A10)

- ปุ่ม "รวมกับงานอื่น" (merge) ในเมนู ⋯ สำหรับงานที่ซ้ำ

## A6 — ต้องติดตาม
- 2 แท็บ: **วันนี้** · **เลยกำหนด** (ส้ม, เรียงจากเลยนานสุด)
- จัดกลุ่มตามเซลล์ (accordion): ชื่อเซลล์ + จำนวน → รายการงาน (รหัส, ลูกค้า, อำเภอ, นัดวันที่, เลยกี่วัน)
- ปุ่ม "คัดลอกรายการไปวางในกลุ่ม" — ข้อความสรุปพร้อมวาง (แทนการ push ที่เสียโควต้า)

## A7 — เซลล์
- แท็บ: **รออนุมัติ (2)** · ใช้งาน · ปิดใช้งาน
- รออนุมัติ: การ์ดต่อคน (รูป LINE, ชื่อ LINE, ชื่อเล่น, พื้นที่ที่กรอก, เวลาสมัคร) + **อนุมัติ** / **ปฏิเสธ**
- ใช้งาน: ตาราง (ชื่อเล่น, พื้นที่, วิ่งงานเดือนนี้, เข้าใช้ล่าสุด) + แก้ไขชื่อเล่น/พื้นที่ (Sheet ด้านขวา) + **ปิดใช้งาน** (มี dialog ยืนยัน: "บอมจะเข้าแอปไม่ได้ทันที งานเดิมยังอยู่")

## A8 — ตั้งค่าตัวเลือก
- รายการที่แก้ได้: ขั้นตอนหน้างาน · ผู้ตัดสินใจ · ประเภทผู้ติดต่อ · สาเหตุจบที่อื่น · ร้านคู่แข่ง · อำเภอ/ตำบลที่ให้บริการ · ช่องบังคับในฟอร์ม LIFF
- แต่ละรายการ: ลากเรียงลำดับ · เพิ่ม · เปลี่ยนชื่อ · ซ่อน (ไม่ลบ เพื่อไม่ให้รายงานย้อนหลังเสีย)

## A9 — ผู้ใช้ระบบ
- ตาราง: ชื่อ · อีเมล · บทบาท (แอดมิน / ดูอย่างเดียว) · ใช้งานล่าสุด · เปิด/ปิด
- เพิ่มผู้ใช้ (dialog) · รีเซ็ตรหัสผ่าน · เปลี่ยนรหัสของตัวเอง (เมนูโปรไฟล์)

## A10 — Export Excel (Dialog)
- ช่วงวันที่ · เซลล์ · สถานะ · ☑ ใส่รูป (ลิงก์) → **ดาวน์โหลด .xlsx**
- คอลัมน์เรียงตามชีทเดิมของทีม (ดู `docs/04_REPORTS_KPI.md`)

## สถานะทั่วไปทุกหน้า
| สถานะ | รูปแบบ |
|---|---|
| โหลด | skeleton ตามรูปทรงเนื้อหา (ไม่ใช้ spinner กลางจอ) |
| ว่าง | ข้อความบอกเหตุ + ปุ่มทำต่อ เช่น "ยังไม่มีหน้างานในช่วงนี้ — ลองขยายช่วงวันที่" |
| Error | แถบแดง soft บนเนื้อหา "โหลดข้อมูลไม่สำเร็จ" + ปุ่ม **ลองอีกครั้ง** |
| บันทึกสำเร็จ | toast (sonner) มุมขวาล่าง ข้อความเดียวกับปุ่ม เช่น "อนุมัติแล้ว" |
| Viewer | ซ่อนปุ่มแก้ไขทั้งหมด แสดงป้าย "ดูอย่างเดียว" ที่ footer sidebar |
