# 04 — รายงาน & KPI (ตามความต้องการรูป 04)

## 1. ตัวชี้วัดที่ลูกค้าขอ → วิธีคำนวณ

ตัวกรองทุกรายงาน: **ช่วงเวลา (วัน/เดือน/ปี)**, **เซลล์**, **พื้นที่ (อำเภอ/ตำบล)**

| # | ความต้องการ | นิยาม / SQL concept |
|---|---|---|
| 1 | จำนวนการวิ่งงานทั้งหมดของเซลล์ | นับ `site_reports` (ทุกครั้งที่รายงาน = 1 การวิ่ง) แยก `new` / `follow_up` |
| 2 | จำนวนงานจบได้ / จบที่อื่น / ยังติดตาม + % | นับ `sites` ตาม `status` ที่ owner_rep = เซลล์ ; % = status / ทั้งหมด |
| 3 | สรุปข้อ 2 แยกตามพื้นที่ของเซลล์ | group by `amphoe`, `tambon` |
| 4 | สาเหตุของงานที่จบที่อื่น | group by `lost_reason` (+ `competitor`) |
| — | แจ้งเตือนวันที่ต้องเข้าไปติดตาม | `next_follow_up_date` (ดู 02 ข้อ 7) |

### นิยามที่ต้องคอนเฟิร์มกับลูกค้า
- "จำนวนการวิ่งงาน" นับ **ทุกครั้งที่รายงาน** หรือ **จำนวนหน้างานที่ไม่ซ้ำ**? (เสนอให้แสดงทั้งคู่)
- งาน "จบได้" ในเดือนไหน — นับตามวันที่จบ หรือวันที่เปิดงาน?
- งานที่ไม่อัปเดตเกิน X วัน ถือว่า "หาย/เลยกำหนด" ไหม?

## 2. หน้าจอ Dashboard (เฟส 2)

- **ภาพรวม:** การ์ด KPI (วิ่งงานวันนี้ / เดือนนี้, จบได้ %, จบที่อื่น %, ติดตามอยู่, เลยกำหนด)
- **เปรียบเทียบเซลล์:** bar chart แยกเซลล์ (stacked: จบได้/จบที่อื่น/ติดตาม)
- **แนวโน้ม:** line chart รายวัน/รายเดือน
- **พื้นที่:** ตาราง/heatmap อำเภอ × สถานะ, แผนที่หน้างาน (pin สีตามสถานะ)
- **สาเหตุจบที่อื่น:** bar chart เรียงมาก→น้อย + คู่แข่ง
- **รายการต้องตาม:** วันนี้ / เลยกำหนด แยกเซลล์
- **หน้างาน detail:** timeline รายงาน + รูปทั้งหมด + แผนที่ + ประวัติสถานะ
- **คิวรอตรวจ**

## 3. Export Excel ให้ตรงกับชีทเดิม (รูป 03)

ทีมใช้ Excel อยู่แล้ว → export คอลัมน์เดิมเพื่อให้เปลี่ยนผ่านง่าย

| คอลัมน์ Excel เดิม | มาจาก |
|---|---|
| ปี.เดือน (`69.08`) | first_reported_at → พ.ศ.2 หลัก.เดือน |
| วันที่ | first_reported_at |
| NO. (`690825-01`) | site_code |
| ชื่อ | customer / contact name |
| เบอร์โทร | contact phone |
| ลูกค้า เก่า/ใหม่ | is_customer_new |
| หน้างาน เก่า/ใหม่ | site_type ของรายงานแรก |
| ตำบล / อำเภอ | tambon / amphoe |
| ผู้มีอำนาจตัดสินใจซื้อ | decision_maker |
| รายละเอียดหน้างาน | รวม reports เป็นบรรทัด `dd.mm ข้อความ` (แบบที่ทีมทำมือใน Excel) |
| วันที่ติดตามล่าสุด | last_reported_at |
| วันที่ต้องเข้าไปติดตามงาน | next_follow_up_date |
| สถานะ | status (ตามต่อ/จบได้/จบที่อื่น/ยกเลิก) |
| หมายเหตุ | note / lost_reason |
| รูป Updated | รูปล่าสุด (ฝังรูปด้วย excelize หรือใส่ลิงก์) |
| โลเคชั่น | `https://maps.google.com/?q=lat,lng` |

## 4. Import Excel เดิม

`cmd/import-excel` อ่านชีทเดิม → สร้าง Site (ใช้ NO. เดิมเป็น site_code), Contact, Report ตั้งต้น
→ เมื่อเซลล์ follow-up งานเก่าใน LINE ระบบจับคู่ได้ด้วยเบอร์/รหัสงาน ทันทีตั้งแต่วันแรก
