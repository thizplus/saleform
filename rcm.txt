ผมจะไล่โค้ด _liff ตัวปัจจุบันก่อน แล้วปรับให้กะทัดรัดขึ้นในโค้ดจริงเลยครับ

ปรับ LIFF ในโค้ดจริงแล้วครับ type-check ผ่าน และ backend ที่แก้ด้วย build ผ่าน ยังไม่ได้เปิดดูหน้าจอจริง เพราะ LIFF ต้องรันผ่าน LINE กับ tunnel ของคุณ ส่วน vite build ในเครื่องที่ผมใช้ทดสอบรันไม่ได้ เพราะ node_modules ติดตั้งมาสำหรับ Windows ฝั่งคุณรันได้ตามปกติครับ

หน้าแรก (งานของฉัน)

ส่วนบนเหลือ 2 แถว (~100px):
แถวชื่อ + ปุ่มค้นหา + ปุ่มผลงาน
แถวแท็บที่มีตัวเลขในตัว: วันนี้ 3 · เลยกำหนด 2 (สีส้ม) · ติดตาม 14 · ทั้งหมด
ตัวเลขใหญ่กับแถบ 7 วันเดิมเอาออกแล้ว พื้นที่ส่วนใหญ่ของจอกลับมาเป็นรายการงาน
ค้นหา: ซ่อนไว้เป็นไอคอน กดแล้วช่องค้นหามาแทนแถวชื่อ และค้นจากงานทั้งหมด
แท็บ "ติดตาม": จัดกลุ่มตามวันนัด เช่น "พรุ่งนี้ · 19 ต.ค. 69" ใช้วางแผนสัปดาห์แทนแถบ 7 วัน
รายการงานเป็นแถวบาง แทนการ์ดใหญ่ แถวละประมาณ 76px เห็นได้ราว 7–8 งานต่อจอ (เดิม 3) แต่ละแถวมี:
ชื่อลูกค้า + ป้ายสถานะ
ช่าง · ตำบล · อำเภอ
รหัสงาน · ตามกี่ครั้ง · รายงานล่าสุดเมื่อไหร่
ไอคอนโทรด้านขวา กดโทรได้ทันที แตะที่อื่นในแถวเพื่อเปิดรายละเอียด
ปุ่ม "รายงานงานใหม่": เปลี่ยนเป็นปุ่มลอยมุมขวาล่าง และซ่อนอัตโนมัติตอนแป้นพิมพ์เปิด (ในภาพที่ส่งมา ปุ่มนี้ไปลอยทับเหนือแป้นพิมพ์)

หน้ารายละเอียดงาน

เบอร์โทร: เป็นข้อความขีดเส้นใต้กดโทรได้ ตามที่บอกครับ
นำทาง: เป็นลิงก์ข้อความต่อท้ายบรรทัดที่อยู่
ข้อมูลหน้างาน: เป็นกล่อง 2 คอลัมน์ แสดงเฉพาะช่องที่มีข้อมูล
รูปทั้งหมด: อยู่ในแถบเลื่อนแนวนอน กดเปิดด้วย lightbox ที่คุณทำไว้
ประวัติการติดตาม: กระชับขึ้น วันที่ / ชื่อเซลล์ / ขั้นตอนอยู่บรรทัดเดียว
ตัดรูปแผนที่ Google Static Map ออก เพราะต้องมี API key และกินพื้นที่มาก
แก้บั๊ก: useState เดิมอยู่หลังจุด return ทำให้หน้านี้ crash ได้ตอนโหลดเสร็จ ย้ายขึ้นไปไว้ก่อนแล้ว

ฟอร์มรายงานงานใหม่ / อัปเดตงาน

ปุ่ม "บันทึกและส่งเข้ากลุ่ม" ซ่อนตอนพิมพ์ ปิดแป้นพิมพ์แล้วจะกลับมา
ชื่อลูกค้ากับชื่อช่างอยู่แถวเดียวกัน
ช่องกรอกเตี้ยลงจาก 48px เป็น 44px และลดระยะห่างระหว่างส่วน

Backend ที่แก้เพื่อให้ข้อมูลครบ

รายการงาน: ส่ง ช่าง, ตำบล, อำเภอ, พิกัด และวันที่รายงานล่าสุดเพิ่มมาด้วย
ก่อนหน้านี้ไม่มีพิกัดในรายการ ปุ่มนำทางในการ์ดเลยกดไม่ได้มาตลอด
บันทึกตำบล/อำเภอจริง: เดิมฟอร์มส่งไปรวมกับที่อยู่เป็นข้อความเดียว จึงไม่ได้เก็บแยก
งานที่สร้างก่อนหน้านี้ยังไม่มีตำบล/อำเภอ ต้องให้แอดมินเติม หรือให้เซลล์อัปเดตเอง
แท็บ วันนี้ / เลยกำหนด / ติดตาม: เรียงตามวันนัด ใกล้สุดขึ้นก่อน
