ต้องแก้ก่อนทดสอบกับเซลล์จริง

คีย์ R2 จริงอยู่ใน _gofiber\.env.example และโปรเจกต์ยังไม่มี git ควรลบ token นี้แล้วออกใหม่ใน Cloudflare ทันที
token ของเซลล์เรียก API ฝั่งแอดมินได้ เพราะเงื่อนไขเช็ก role ใน middleware/auth.go ปล่อยผ่าน
ใครมีบัญชี LINE ก็เข้า LIFF ได้ทันที เพราะสร้างเป็น active ทั้งที่คอมเมนต์เขียนว่า pending คนนอกที่ได้ลิงก์จะเห็นชื่อและเบอร์ลูกค้าทั้งหมด
ระบบสร้างรายงานได้แค่รายการเดียว เพราะ IdempotencyKey ตั้งเป็น unique แต่ไม่เคยใส่ค่า ทุกแถวเป็นค่าว่างเหมือนกัน รายการที่ 2 จึงชน
เบอร์โทรเดียวกันมีได้แค่หน้างานเดียว (Contact.Phone เป็น unique) ช่างที่รับหลายหน้างานจะบันทึกไม่ได้
รหัสงานซ้ำได้ถ้ากดพร้อมกัน เพราะเพิ่มเลขกับอ่านเลขแยกกันคนละคำสั่ง
LIFF บนมือถือเรียก API ไม่ได้
VITE_API_URL ยังชี้ไปที่ localhost
CORS ไม่มีโดเมน liff.puekk.com
vite.config.ts ยังไม่มี allowedHosts ทำให้เปิดผ่าน tunnel ไม่ได้
รูปไม่แสดง เพราะ API ส่งชื่อไฟล์กลับไปแทน URL และระบบไม่เคยสร้างรูปย่อจริง
server ล่มได้จาก error เดียว เพราะไม่มี recover middleware

ยังขาดตาม requirement (รูป 04)

อำเภอ/ตำบลไม่ถูกบันทึกเลย จึงสรุปผลตามพื้นที่ไม่ได้
ฟอร์มส่งวันคาดการณ์สั่งของเป็นค่าว่างตายตัว ไม่มีช่องให้กรอก
ตัวเลข "ต้องตามวันนี้" ได้สูงสุดแค่ 1
ฝั่งแอดมินยังไม่มี Dashboard/KPI, หน้ารายละเอียดหน้างาน, Export Excel และการอนุมัติเซลล์ใหม่

Clean Architecture ยังไม่สะอาดในบางจุด

handler บางตัวใช้ repository ตรง
service บางตัว import infrastructure โดยตรง
SeedAdmin อยู่ใน handler และสร้างแอดมินรหัส admin1234 ทุก environment รวม production ด้วย
