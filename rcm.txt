***ขอเพิ่มเติมรายงานสรุปประจำวันอีกนิดค่ะ  (เซลล์เป็นคนกรอก)
22/11/69
req.หน้าเพิ่มงาน
- ปรับแก้ไขข้อความ "ขั้นตอน" เป็น สถานะงาน  ในหน้าเพิ่มงานใหม่
- เพิ่ม section ตัวเลือกงานอื่น ใต้ขั้นตอนครับ โดย option นี้ admin ต้องกำหนดค่าที่ดึงมาแสดงได้ใน admin option ด้วยนะครับ  และต้องมีให้เลือกอื่นๆ ให้ sale พิมพ์ข้อความงานที่นอกเหนือได้ด้วย
- ช่องหมายเหตุ ของเดิมเป็นช่องหมายเหตุ แก้ไขเป็นช่อง "สินค้าที่สนใจ"
- ใต้ช่องหมายเหตุ เพิ่มอีก section เป็นช่อง รายละเอียดหน้างาน  ให้เซลกรอกข้อมูลเองเป็น textarea เหมือน ช่องหมายเหตุ แต่ไม่ต้องมีปุ่ม queuck message

เช็คอินเย็น (ของเดิมเป็นระบบ เช็คอินเช้า อย่างเดียว  เลยอยากเพิ่ม ปุ่มให้กด สรุปงานประจำวัน  จะขึ้นต่อเมื่อ เคยเช็คอินแล้ว)
- สรุปงานของ sale โดยจะต้องส่ง message ไปในกลุ่ม เหมือนสรา้งงานใหม่ โดยมีรายละเอียดที่เซลต้องกรอก ตามนี้

- กรอกเลขไมล์ รถคันที่ใช้ตอนเช็คอินเมื่อเช้า 
- โทรติดตามลูกค้ากี่ราย
- เปิดบิลกี่บิล
- ยอดบิล ลค.เก่า
- ยอดบิล ลค.ใหม่ 


สรุปเข้าไลน์เหมือนเดิม

และทั้งนี้ ต้องปรับ admin web ให้รองรับ field ต่างๆที่เพิ่มเข้ามาด้วยนะครับ
